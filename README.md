# 🛍️ Pine Berry

**Pine Berry** is a **feature-rich e-commerce platform** designed for online product sales.  
It offers **product catalog management**, **shopping cart functionality**, **secure checkout**, and **order tracking**, along with **user reviews** to help improve customer shopping confidence.  

Built with a mobile-first approach, **Pine Berry** ensures smooth and secure shopping experiences for customers.

---

## ✨ Features

- **📦 Product Catalog** – Browse a wide range of products with descriptions, images, and prices  
- **🛒 Shopping Cart** – Add, update, and remove products; view cart summary before checkout  
- **🔒 Secure Checkout** – Powered by **Stripe** for safe and seamless payments  
- **🚚 Order Tracking** – Track your order from purchase to delivery in real time  
- **⭐ User Reviews & Ratings** – Improve decision-making with authentic customer feedback  
- **📍 Store Locator via Google Maps** – Easily find physical store locations

---

## 🛠️ Tech Stack

**Mobile Development:**
- Android Studio (Java & XML)

**Backend & Data Storage:**
- Firebase (Authentication, Realtime Database / Firestore, Cloud Storage)

**Maps Integration:**
- Google Maps API

**Payments:**
- Stripe Payment Gateway
